# CRM activity chart

The Agent Report shows a five-minute histogram below the detailed table for Date end, using the loaded agent filter (one agent or all agents). The 216 intervals span 06:00?23:59 in Europe/Bucharest, consistent with the report. Successful explicitly mapped server actions with recent interaction or confirmed updates and authenticated persisted simulations count as events; browser presence, failed or replayed actions, support-account activity and simulation request duplicates are excluded. Empty intervals remain visible. Hover or keyboard focus shows the interval count. Historical coverage follows the existing telemetry coverage; unavailable metrics are labelled unavailable.

Recent-interaction attribution is observational: requests occurring within two seconds of input can include a coincident refresh. Counts are recorded requests, not a claim of one unique physical action per event.
